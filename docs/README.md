# Documents — what to read, in order

Twenty-three documents. You do not need all of them. Pick the row that matches why
you are here.

| If you want to… | Read |
|---|---|
| Understand the study in one sitting | `FINAL_REPORT.md` |
| Know what the paper is asking and claiming | `RESEARCH_QUESTION.md` |
| Write the paper | `PAPER_OUTLINE.md` |
| Check a specific number | `COMPLETE_RESULTS.md` |
| Know where quantum won and where it could | `QUANTUM_ADVANTAGE.md` |
| Learn the whole project from scratch | `THE_DOCUMENT.md` |
| Reproduce or review the method | `METHODS.md` |

## A note on corrections

Several claims in earlier drafts were wrong. They are **corrected in place, with
the original quoted and dated**, rather than silently deleted — in
`FINAL_REPORT.md` §1 and §2, `RESULTS_SWEEP.md` §1–§4, `QUANTUM_ADVANTAGE.md` §1
and §5, and `../figures/README.md`. If a number here disagrees with a number in
an older document, the newer one is right and the older one should say so.
