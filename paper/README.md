# The paper

LaTeX source, IEEE two-column. Target: IEEE Transactions on Quantum Engineering.

```
main.tex       the whole paper: preamble, structure, figures, section stubs
refs.bib       every reference, from the verified docs/CITATIONS*.md entries
tables/        GENERATED by scripts/27_paper_tables.py -- never edit by hand
figures/       the 15 paper figures, copied from ../figures/
```

## Compiling

**Overleaf (no install needed).** Zip this `paper/` folder, upload it as a new
project, set `main.tex` as the main document. IEEEtran ships with Overleaf.

**Locally.** Needs MiKTeX (`winget install MiKTeX.MiKTeX`) or TeX Live:

```
latexmk -pdf main.tex
```

## The one rule

**Never type a result into a `.tex` file.** Every table comes from
`scripts/27_paper_tables.py`, which reads the same CSVs as
`docs/COMPLETE_RESULTS.md`. When a result file changes:

```
python scripts/27_paper_tables.py
```

and the paper updates. A number typed by hand will eventually disagree with the
data, and a reviewer will find it before you do.

Figures work the same way: `scripts/24_figures.py` and `scripts/28_paper_figures.py`
write `../figures/`; copy the ones `main.tex` uses into `figures/` here. Two of them
(18, 19) are the held-out-test versions of the validation figures 04 and 05.

## Writing order

Method → Results → Discussion → Introduction → Conclusion → Abstract.

The introduction is much easier once you know exactly what you found, and an
abstract summarises a finished paper rather than a planned one.

Every section in `main.tex` opens with a `% WRITE` block: what that section must
do, which numbers to quote, which figure carries it, and the trap to avoid.
Delete each block as you write it. Fuller guidance is in
`../docs/PAPER_OUTLINE.md`, and the claims the paper may and may not make are in
`../docs/RESEARCH_QUESTION.md`.

## Switching venue

`\documentclass[journal]{IEEEtran}` → `\documentclass[conference]{IEEEtran}` for
an IEEE conference such as QCE. Conference format is tighter; expect roughly
8--10 pages against 18--20, so the appendices would move to the repository.
